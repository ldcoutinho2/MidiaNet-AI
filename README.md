# MidiaNet AI

SaaS da MidiaNetDigital para análise estratégica e crescimento no Instagram.

## Fluxo do produto

Conectar Instagram → analisar perfil → entender objetivo do cliente → perguntas adaptativas → DNA do perfil → estratégia → medir resultados → aprender.

## MVP

- Landing page
- Cadastro/login
- Onboarding estratégico
- Conexão oficial do Instagram via Meta
- Análise inicial
- DNA do perfil
- Dashboard
- Estratégia semanal
- Eventos e funil
- Assinaturas e pagamentos

## Princípios

- Instagram primeiro.
- Nunca pedir senha do Instagram.
- Métricas e cálculos ficam no sistema; a IA interpreta dados estruturados.
- O objetivo declarado pelo cliente orienta a estratégia.
- Arquitetura modular para evitar regressões.
- TikTok fica para uma fase posterior.
